# emg-waveform-overlay

SpikerBox Pro의 근전도(EMG) 신호를 **Spike Recorder 스타일 파형**으로 화면 위에 띄우는 작은 오버레이입니다.
게임 같은 다른 창 위에 항상 떠 있고, 마우스 클릭은 아래 창으로 그대로 통과합니다.

- 어두운 배경 + 격자 + 흐르는 파형 (Spike Recorder 와 같은 색, 열마다 최소·최대를 이은 방식)
- 쉴 때는 연두색, 힘을 주면(RMS 가 기준 이상) 주황색
- 오른쪽 위에 현재 RMS 와 초당 프레임 수
- Windows 전용 (클릭 통과 때문에), Python 3.10 이상

## 값은 어떻게 읽나

`Muscle SpikerBox Pro (USB HID, 2E73:0001)` 는 시리얼 포트가 아니라 **USB HID 장치**입니다. 값 읽기는 실기기에서 정확히 읽히는 것을 확인한 `emg.py` 와 같은 규칙입니다.

- 64바이트 보고서 `[0x3F, 길이, 데이터…]`, 시작 명령 `start:;` → `board:;`, 끝낼 때 `h:;`
- 채널 수는 `BRD` 메시지로 정하고(기본 2), 프레임은 다음 시작 바이트가 왔을 때 길이가 맞고 값이 모두 1023 이하일 때만 받습니다(10비트). 기기 메시지는 샘플로 새지 않습니다.
- 신호: `raw − 512` → 60 Hz 노치 → 2500 Hz 저역 → 1 Hz 고역, 켠 직후 1초는 안정화 구간으로 버립니다.
- 장치가 빠지거나 3초 동안 신호가 없으면 닫고 1초마다 다시 찾습니다.

검증 (2026-10-20): 무작위 500개 보고서 스트림(깨진 바이트, 1023 초과 값, 긴 기기 메시지, 채널 수 변경, 잘못된 보고서)과 실기기 캡처 3개(8~20초)에서 프레임이 `emg.py` 와 **완전히 같았고**, 필터 출력도 차이 0이었습니다. 실기기는 초당 약 10,050 프레임이 들어왔습니다.

## 실행

```bat
py -m pip install -r requirements.txt
py emg_overlay.py
```

또는 `run.bat` 을 더블클릭합니다. SpikerBox 를 USB 에 꽂고 전원을 켜면 자동으로 찾아 연결합니다. **Spike Recorder 나 다른 프로그램이 장치를 잡고 있으면 열리지 않으니** 먼저 끄세요. 종료는 콘솔 창에서 `Ctrl+C` 입니다.

| 옵션 | 기본 | 설명 |
|---|---|---|
| `--channel 1\|2` | 1 | 표시할 채널 |
| `--seconds` | 2 | 화면에 보이는 시간(초) |
| `--scale` | 200 | 세로 맨 위·아래 끝의 값(ADC 카운트). 센 신호가 꽉 차면 키우세요 |
| `--threshold` | 15 | 이 RMS 이상이면 주황색 |
| `--notch 60\|50\|off` | 60 | 전원 잡음 노치 (한국은 60) |
| `--alpha` | 0.95 | 창 투명도 (0.3~1) |
| `--x`, `--y` | 오른쪽 가운데 | 창 위치 |
| `--replay FILE` | – | 장치 없이 저장해 둔 64바이트 보고서 파일을 실제 속도로 되풀이 재생 (시연·확인용) |

## 테스트

```bat
py -m unittest discover -s tests
```

디코더(청크 경계, 1023 초과, 긴 메시지, 채널 수), 필터 이득(60 Hz 는 거의 제거, 150 Hz 이상은 통과), 파형 압축, 읽기 스레드(가짜 장치로 시작 명령 확인), 재생기를 장치 없이 검사합니다.
