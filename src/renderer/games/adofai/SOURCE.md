# 얼음과 불의 춤 — 내장 WebGL 빌드

`assets/webgl/`에 실행 가능한 Unity WebGL 빌드를 포함한다. 사용자가 제공한 로컬 게임 파일에서 복원한 프로젝트를 Unity 6000.3.10f1로 빌드했다. 원본 게임의 코드·그래픽·음원에 대한 권리는 원저작자에게 있다.

## 실행과 패키징

저장소 복제 후 `git lfs pull`, `npm install`, `npm start` 순서로 실행한다. `npm run build:win`은 에셋까지 포함한 Windows 포터블 exe를 만든다. 큰 `.data`, `.wasm`, `.webm` 파일은 Git LFS로 관리한다. 게임 외 연구용 맵·음원 추출물은 포함하지 않는다.

`adofai://game/index.html`은 `src/main/adofai-protocol.js`가 이 빌드 폴더의 파일로 연결한다. Steam을 실행하지 않으며, Esc는 게임 일시정지에 전달하고 Ctrl+Q로 게임 창을 닫는다. 게임 내부 메뉴와 로딩을 포함한 Unity 런타임이 실행되므로 첫 로딩에는 시간이 걸린다.

## 포함된 빌드의 복원 내용과 검증 범위

- WebGL용 일시정지·설정 메뉴 항목과 한글 동적 글꼴 아틀라스를 복원했다.
- 제목의 세 마스크 이미지를 원본 Alpha8 형식으로 복원했다. FIRE·ICE가 늘어나지 않도록 원본 1024×301 Sprite 영역, 중심점, 잘린 영역의 오프셋을 복원했다.
- 로컬 실행에서 제목 색상·배치를 확인했다. 전체 맵 플레이와 실제 EMG 장치 입력은 재검증하지 않았으며 원작과 완전히 동일하다고 보장하지 않는다.

이 저장소에는 실행 및 Electron 패키징에 필요한 WebGL 산출물을 포함한다. Unity 복원 프로젝트와 그 편집기 자체는 포함하지 않으므로 게임 내부를 다시 수정해 WebGL로 빌드하려면 별도의 Unity 프로젝트가 필요하다.
