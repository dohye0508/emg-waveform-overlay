# 비행기 (헬리콥터류) — 외부 코드 + 공개 그림

- 물리·게임 틀: https://github.com/orangespaceman/js-canvas-copter (`master`, 커밋 `ad21c9c0ce1cea15db9c4f3c0ffdef4e43eb2cb9`, 2018-09-05), 라이선스 WTFPL (`COPYING`).
  사용자가 브라우저로 본 JS-Heli·Gravity Jumper 는 라이선스가 없어 가져올 수 없어서, 같은 장르에서 쓸 수 있는 이 리포를 썼다.
- 그림: Kenney "Tappy Plane" 1.1 (https://kenney.nl/assets/tappy-plane), 라이선스 CC0 (`assets/Kenney-License.txt`). 처음에는 캔버스에 직접 그렸는데 사용자가 품질이 낮다고 해서 이 그림으로 바꿨다.
- `script.js` 에서 고친 것:
  - 그리기를 빼고(art.js 가 그림) 위치 계산·충돌만 남김.
  - 물리: 원작은 떨어질 때 속도가 몇 프레임 만에 일정해져서 부자연스러웠다 → 중력·위로 미는 힘을 매 프레임 더하고 공기 저항을 곱해, 점점 빨라지고 점점 느려지게. 기수 각도도 세로 속도를 부드럽게 따라감.
  - 장애물: 공중 사각형 대신 바닥·천장에서 솟은 바위 첨탑(가끔 위아래 한 쌍, 시간이 갈수록 길어짐), 판정은 삼각형. 별을 모으면 3점, 첨탑을 지나면 1점. 동굴 벽은 일정한 두께(바닥 풀밭·천장 바위 띠).
  - 입력: 어디서든 마우스 버튼이나 Esc 를 뺀 아무 키, 누르는 동안 상승. 추락 뒤 1.2초는 다시 시작하지 않음. 최고 점수는 localStorage(`planeBest`).
- `start.js`: 게임 좌표 높이 480(그림 원래 크기), 가로는 창 비율. 속도·중력은 높이에 맞춰 조정.
- `art.js` (EMG Overlay 가 씀): 하늘 배경 시차 스크롤, 풀밭·바위 띠, 첨탑, 반짝이며 떠다니는 별, 프로펠러가 도는 비행기와 연기, 추락하면 빙글 떨어지며 연기가 터지고 화면이 흔들림, GET READY·GAME OVER 그림, 결과판·메달, 숫자는 Kenney 숫자 그림(점수·최고 모두), 글자는 주아체.
